# Logistics Dashboard

A demo logistics dashboard built with Next.js, React and TypeScript. It provides a simple control-centre view of simulated logistics operations, including fleet activity, drivers, operational events and support tickets.

## Features

- Overview of logistics operations
- Fleet and truck activity
- Driver activity and location views
- Live-style operational event feed and activity timeline
- Ticket tracking
- Simulated data and events for demonstration purposes

## Getting Started

### Requirements

- Node.js 20.9 or later
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for production

```bash
npm run build
```

The project is configured for static export and deployment to GitHub Pages.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
